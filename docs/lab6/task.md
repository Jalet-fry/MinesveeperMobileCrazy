# Лабораторная работа №6: «Улучшение UX»

## Краткий конспект
Атрибуты качества ПО группы “Usability” (согласно ISO/IEC 25010:2011):
*   **Распознаваемость соответствия** (Appropriateness recognizability)
*   **Обучаемость** (Learnability)
*   **Используемость / Операбельность** (Operability)
*   **Защита от ошибок пользователя** (User error protection)
*   **Эстетика GUI** (User interface aesthetics)
*   **Доступность** (Accessibility)

## Требования и стандарты
*   Microsoft Usability
*   Apple Usability
*   Google Usability
*   WCAG 2.0 (для web-приложений)

## Уровни «Опыта использования»
1.  **Поверхность:** Внешний вид (текст, картинки, кнопки).
2.  **Компоновка:** Расположение элементов UI.
3.  **Структура:** Навигация между страницами/окнами.
4.  **Набор возможностей:** Функциональные возможности.
5.  **Стратегия:** Желания и ожидания пользователей и заказчика.

## Задание на работу
1.  **Оценить разрабатываемое ПО** по всем шести атрибутам (дать краткую оценку согласно определению).
2.  **Выбрать пути улучшения UX**, обосновать необходимость.
3.  **Провести улучшения.**
4.  **Привести сравнение «до» vs. «после»** (картинки/описания).
5.  **Оформить в виде отчёта**, выложить в репозиторий.
