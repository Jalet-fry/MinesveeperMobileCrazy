# Отчет по Лабораторной работе №6: «Улучшение UX»

## 1. Оценка разрабатываемого ПО по атрибутам Usability (ISO/IEC 25010)

| Атрибут | Оценка | Описание |
| :--- | :--- | :--- |
| **Распознаваемость** | Высокая | Иконки мин, флагов и чисел соответствуют классическим стандартам "Сапера", что делает продукт узнаваемым. |
| **Обучаемость** | Средняя | Новые механики (заряды мин, анти-мины) требуют времени на освоение, так как в приложении нет встроенного обучения. |
| **Используемость** | Высокая | Реализован Zoom (щипком) и Drag для навигации по большим полям. Есть переключение инструментов "Копать/Флаг". |
| **Защита от ошибок** | Хорошая | Флаг блокирует случайное открытие ячейки. Есть подтверждение выхода во время активной игры. |
| **Эстетика GUI** | Средняя | Интерфейс чистый, на Jetpack Compose, но меню настроек выглядит перегруженным из-за большого количества параметров. |
| **Доступность** | Низкая | Приложение не адаптировано для TalkBack и не имеет специальных высококонтрастных тем. |

## 2. Пути улучшения UX
* **Внедрение Onboarding**: Добавление краткого туториала при первом запуске уровня с "зарядами".
* **Haptic Feedback**: Добавление вибрации при установке флага и взрыве.
* **Упрощение настроек**: Группировка параметров генерации поля по вкладкам (Базовые/Продвинутые).

## 3. Проведенные улучшения
1. Добавлен визуальный индикатор активного инструмента в ToolBar.
2. Реализована система быстрых подсказок в статус-баре.
3. Добавлен анимационный эффект при победе.

## 4. Сравнение "До" vs "После"
*(Место для скриншотов)*
* **До**: Статичная сетка, неочевидное состояние выбора инструмента.
* **После**: Анимированные переходы, выделение выбранного типа флага, вибрация.

## 5. Вывод
Проведенные улучшения позволили снизить когнитивную нагрузку на игрока и сделали процесс взаимодействия с нестандартными механиками более прозрачным.
